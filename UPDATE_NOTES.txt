Southern Nutrition Worker V18

Admin dashboard upgrades:
- Shows all customer accounts (no 250-row cap).
- Search by customer ID, name, phone, or email.
- Edit customer name, phone, and email.
- Optional admin password reset (new passwords are PBKDF2 hashed; existing passwords are never visible).
- Disable/re-enable customer accounts. Disabled accounts cannot log in and active sessions are removed.
- Admin cannot disable their own account.
- Adds active/disabled account status and disabled-account count.
- Adds read-only Square Loyalty balance and lifetime points to the admin dashboard when Square Loyalty/API credentials are available.
- Loyalty lookup uses Square customer IDs already linked to Southern Nutrition accounts.
- If Square/Loyalty is not configured yet, the dashboard clearly says loyalty balances are not available rather than inventing points.

Security:
- All admin reads/edits are protected server-side by is_admin.
- Password hashes and Square access tokens are never returned to the browser.
- /admin remains noindex/noarchive.
- New is_disabled D1 column is created automatically on first admin/API use.

Important:
Editing name/phone/email in this admin dashboard updates the Southern Nutrition D1 account only. It does not currently edit the customer's Square Customer profile.
