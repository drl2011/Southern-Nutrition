Southern Nutrition V8

- Replaced demo/localStorage customer login with Cloudflare D1-backed accounts.
- Passwords are PBKDF2-SHA256 hashed; raw passwords are never stored.
- Added secure HttpOnly/Secure/SameSite session cookies with a 30-day session.
- Added signup, login, logout, and current-session API endpoints.
- Signup creates or links a Square Customer profile and stores only the Square customer ID in D1.
- Logged-in Square payments are now attached to that Square customer ID.
- Account profile shows whether Square linking is ready.
- Reward UI is ready for Square Loyalty; actual points remain disabled until a Square Loyalty program/subscription is enabled and connected.
- Email is required for new accounts because the current D1 users table requires it.
- Password minimum is now 8 characters.
- Bumped cart storage key to V8 and safely migrates valid old cart items.
- Added the D1 binding to wrangler.jsonc so GitHub/Cloudflare deployments keep the DB connection.
